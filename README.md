# SpringTaskRESTful

It implements RestController and adds the following functionalities:

1. Get a certain course by its name
2. Add a course using an html form

![image](https://github.com/user-attachments/assets/73f4f109-a48b-45d1-a9cb-78e36a63f38d)

3. Update course details
4. Delete a course by its id
5. View all courses

Swagger is used for interacting with all the requests except for adding a new course which is handled through an html form
